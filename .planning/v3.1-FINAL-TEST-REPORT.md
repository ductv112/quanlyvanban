## 🚨 6 BUGS P0/P1 — BẮT BUỘC FIX TRƯỚC ĐÀM PHÁN KH

### P0 — Block go-prod hoàn toàn

#### 1. BUG-E2E-018 (P0) — LGSP tracking SP signature mismatch → liên thông HOÀN TOÀN không hoạt động
- **File:** `e_office_app_new/backend/src/repositories/outgoing-doc.repository.ts:305,312` + `incoming-doc.repository.ts:376`
- **Symptom:** Backend gọi `fn_lgsp_tracking_create` với 8 args (last param `'lgsp'/'cp'` channel), SP chỉ có 7 args → mọi gửi LGSP fail
- **Impact:** Không thể gửi VB qua LGSP/CP — chức năng liên thông giữa các đơn vị hoàn toàn vỡ
- **Fix:** Add `p_channel VARCHAR(10)` param vào SP `edoc.fn_lgsp_tracking_create`. Estimate **15-20 phút**.

#### 2. BUG-CONC-003 (P0) — Race condition notation outgoing doc → 2 VB cùng số trong 1 sổ
- **File:** SP `edoc.fn_outgoing_doc_get_next_number` + DB schema `edoc.outgoing_docs`
- **Symptom:** 2 concurrent POST `/api/van-ban-di` cùng `doc_book_id` → DB tạo 2 row duplicate `notation`. SP dùng `MAX+1` không atomic, không có UNIQUE INDEX.
- **Impact:** **Vi phạm nghiệp vụ lõi cơ quan nhà nước** — văn thư tuyệt đối không thể có 2 VB cùng số ký hiệu trong 1 sổ năm
- **Fix:** Add UNIQUE INDEX `(doc_book_id, number, year)` + dùng PostgreSQL sequence per book hoặc `SELECT FOR UPDATE` trong SP. Estimate **30-45 phút**.

### P1 — Block triển khai KH thật

#### 3. BUG-001 (P1) — Missing endpoint user tự đổi mật khẩu
- **File:** `e_office_app_new/backend/src/routes/auth.ts` (cần add)
- **Symptom:** POST `/api/auth/change-password` → 404. Chỉ admin reset password user khác qua `admin.ts:575`. User không thể tự đổi mật khẩu trên trang Thông tin cá nhân.
- **Impact:** 10 TC fail. UX kém (user phải nhờ admin đổi mật khẩu).
- **Fix:** Tạo SP `public.fn_staff_change_password` + route POST `/api/auth/change-password` với JWT auth + validate (old match, new ≥6+chữ hoa+thường+số, confirm match, new≠old) + bcrypt hash + revoke refresh tokens. Estimate **30-45 phút**.

#### 4. BUG-PERM-008 (P1 SECURITY) — Refresh token rotation BROKEN (replay attack)
- **File:** `e_office_app_new/backend/src/services/auth.service.ts` refresh logic
- **Symptom:** Old refresh-token cookie still accepted after a successful `/refresh` (should be single-use per CLAUDE.md design). Cho phép replay leaked refresh tokens until 7d expiry.
- **Impact:** **Security hole HIGH** — attacker chiếm refresh token có thể dùng vô hạn lần trong 7 ngày
- **Fix:** Implement single-use refresh token: hash token cũ vào DB, mark used trên `/refresh`, reject lần 2. Estimate **45-60 phút**.

#### 5. BUG-F-VB-006 (P1 SECURITY) — Upload .exe (mọi extension) accepted
- **File:** `e_office_app_new/backend/src/middleware/upload.ts`
- **Symptom:** Multer không có MIME/extension whitelist. Upload `.exe`, `.bat`, `.sh` được chấp nhận → user có thể upload malware vào hệ thống
- **Impact:** Security risk đặc biệt với hệ thống có user công chức ít hiểu IT
- **Fix:** Add MIME whitelist trong fileFilter: chỉ cho `pdf, doc, docx, xls, xlsx, jpg, png, txt, zip, rar, 7z`. Estimate **15 phút**.

#### 6. BUG-CATALOG-SHADOW (P1 architectural) — server.ts mount order shadow admin routes
- **File:** `e_office_app_new/backend/src/server.ts:72-74`
- **Symptom:** `publicCatalogRoutes` mount BEFORE `adminCatalogRoutes` cùng prefix `/api/quan-tri` → admin routes bị shadow. Chỉ trả subset fields + hardcoded filter `is_active=true`/`is_locked=false`.
- **Impact:** **9 bug cumulative cùng root cause:**
  - BUG-ND-001 (HIGH): admin filter "Đã khóa" không work
  - BUG-ND-002 (HIGH): admin search username không work  
  - BUG-DMSV-001 (HIGH): cột "Mặc định" "Mô tả" "Thứ tự" trống
  - BUG-DMLV-001+002 (CRITICAL): 3 tab Loại VB hiển thị y hệt
  - BUG-DMLN-001+002+003 (CRITICAL): Lĩnh vực không filter, không edit inactive
  - BUG-DMNK-002 (HIGH): Modal Thêm người ký dropdown rỗng khi chọn dept cha
- **Fix gom 1 line:** swap order `adminCatalogRoutes` BEFORE `publicCatalogRoutes`. Estimate **5 phút**.
