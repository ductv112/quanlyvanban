## Known Caveats

1. **Credential rotation HTTP 401:** Test connection có thể trả 401 nếu credential từ Excel/List.txt đã rotate. Same caveat Phase 34-05/35-05/36-05.
   - **Mitigation:** Admin nhập credential mới qua `/lgsp/cau-hinh` → Test connection → PASS → toggle `is_active=true`. UI flow handle full self-service.
2. **`SIGNING_SECRET_KEY` persistence:** NẾU thay đổi sau khi đã encrypt credential → toàn bộ DB secret KHÔNG decrypt được → phải nhập lại. Set 1 lần từ đầu + backup an toàn (CLAUDE.md pitfall #14).
3. **Worker race tick+event same-queue (Phase 35-05 + 36-05 inherited):** First attempt always succeeds; affected only retry race. Defer split queues v3.3+.

5. **Bulk retry admin page:** Defer v3.3+ — per-event/per-tracking retry inline UI đủ cho v3.2 (CONTEXT 37 D-08).
6. **MongoDB audit log LGSP:** Defer v3.3+ (LGSP-AUDIT-LOG REQ).
7. **DLQ table tách:** Defer v3.3+ (LGSP-DLQ REQ).

- **BullMQ workers** (Phase 34/35/36) — async producer/consumer, retry exponential backoff
- **Approach B duplicate workers/** (Phase 34 ratified) — workers self-contained, manual sync discipline (tradeoff: parser/builder duplicated; benefit: workers tsc isolated from backend `rootDir`)
- **Per-unit credential lookup factory** (Phase 33) `getLgspService(unit_id)` với cache invalidate-on-write
