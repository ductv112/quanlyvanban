# KỊCH BẢN ĐÀO TẠO HỆ THỐNG QUẢN LÝ VĂN BẢN

**Tài liệu để Team BA dựng Slide**

---

## THÔNG TIN CHUNG

| Mục | Nội dung |
|---|---|
| Tên buổi | Đào tạo Hệ thống Quản lý Văn bản điện tử |
| Đối tượng | Cán bộ, công chức, chuyên viên (Văn thư, Lãnh đạo, Chuyên viên xử lý) |
| Tổng thời lượng | **90 phút** |
| Phân bổ thời gian | Slide 20-25' → Demo 50' → Q&A & phát tài khoản 15-20' |
| Số slide | **12 slide** (gọn, không lan man) |
| Sau buổi học | KH thực hành tại đơn vị, đội hỗ trợ trực từ xa qua Zalo/điện thoại |

**Triết lý buổi đào tạo:** Slide chỉ định hướng — phần chính là **demo trực tiếp** + **thực hành**. Không biến slide thành HDSD chi tiết.

---

## CÁC PHÂN HỆ TRÌNH BÀY (đã rà với menu hệ thống hiện tại)

**Có giới thiệu:**

- Văn bản đến / Văn bản đi / Văn bản dự thảo
- Hồ sơ công việc
- Thông báo (notification)
- Ký số (SmartCA + Viettel CA)

**KHÔNG nhắc đến trong slide:**

- Lịch họp / Cuộc họp / Tin nhắn / Danh bạ
- Kho lưu trữ / Tài liệu / Hợp đồng
- LGSP (liên thông cơ quan ngoài)
- Các mục quản trị nâng cao (chỉ Admin dùng — không phải user cuối)

---

## QUY ƯỚC CHO TEAM BA

Mỗi slide có 5 phần:

- **Layout** — bố cục, vị trí thành phần
- **Headline** — tiêu đề in trên slide
- **Nội dung** — text + bullet hiển thị trên slide (paste được)
- **Visual** — gợi ý hình ảnh, icon, screenshot
- **Note thuyết trình** — giảng viên nói thêm (KHÔNG in lên slide)

**Quy ước hình thức:**

- Tỉ lệ slide: 16:9
- Font: Inter / Plus Jakarta Sans / Be Vietnam Pro
- Tông màu: Deep Navy `#1B3A5C` + Teal `#0891B2` (đồng bộ hệ thống)
- Mọi text UI/screenshot: tiếng Việt có dấu

# SLIDE 4 — SƠ ĐỒ LUỒNG VĂN BẢN CỐT LÕI (3 phút)

**Nội dung sơ đồ:**

```
[Văn bản đến] → [Văn thư tiếp nhận] → [Lãnh đạo chỉ đạo]

```

**Chú thích 3 vai trò (dưới sơ đồ):**

- **Văn thư**: vào sổ, scan, cấp số, phát hành

- **Chuyên viên**: xử lý nội dung, soạn văn bản đi

**Visual:**

- Sơ đồ 6 node hình tròn nối nhau bằng mũi tên teal
- Mỗi node có icon biểu thị bước
- Node "Ký số" highlight đậm + có 2 logo nhỏ: SmartCA + Viettel CA

**Note thuyết trình:** Mỗi anh/chị sẽ đóng 1 trong 3 vai trò trên — tùy vị trí. Phần demo lát nữa sẽ chạy đầy đủ cả luồng này.

# SLIDE 6 — ĐĂNG NHẬP & GIAO DIỆN (2 phút)

**Layout:** Bên trái screenshot trang đăng nhập, bên phải hướng dẫn 4 bước.

**Headline:**

> **Đăng nhập lần đầu — 4 bước đơn giản**

**Nội dung 4 bước:**

1. Mở trình duyệt (Chrome / Edge / Cốc Cốc) → vào `[URL hệ thống]`
2. Nhập **tên đăng nhập** + **mật khẩu** (do Quản trị viên cấp)
3. **Đổi mật khẩu ngay** trong lần đầu — bắt buộc
4. Lưu URL vào dấu trang để truy cập nhanh

**Lưu ý quan trọng (box vàng cảnh báo):**

- Không chia sẻ tài khoản cho người khác
- Quên mật khẩu → liên hệ Quản trị viên đơn vị

**Visual:**

- Screenshot trang login thật (làm mờ thông tin nhạy cảm)
- Bên phải: 4 bước với số tròn navy
- Box cảnh báo màu vàng nhạt

**Note thuyết trình:** Phần thao tác đăng nhập + làm quen giao diện sẽ demo chi tiết lát nữa — slide chỉ giới thiệu nguyên tắc.

# PHỤ LỤC A — KỊCH BẢN DEMO TRỰC TIẾP (50 phút)

## Chuẩn bị môi trường demo

| Hạng mục | Yêu cầu |
|---|---|
| Máy chiếu | Tối thiểu Full HD, test trước 30 phút |
| Mạng | Internet ổn định, dự phòng 4G/5G |
| Trình duyệt | Chrome/Edge mới nhất |
| Tài khoản test | 1 Văn thư + 1 Lãnh đạo + 1 Chuyên viên (3 cửa sổ ẩn danh) |
| Chứng thư số | SmartCA test + Viettel CA test (đăng ký sẵn cho tài khoản Lãnh đạo) |
| Dữ liệu mẫu | 2-3 văn bản đến mẫu, 1 file PDF mẫu (~2MB), 1 file Word dự thảo mẫu |

## Demo 1 — Đăng nhập & Giao diện (5')

1. Mở Chrome → URL hệ thống → Login tài khoản Văn thư
2. Demo đổi mật khẩu (làm rồi quay lại để tiếp tục)
3. Đi qua Sidebar: Văn bản đến / đi / dự thảo / Hồ sơ
4. Mở Header: Thông báo, tài khoản, đăng xuất
5. Quay lại Dashboard, giải thích các widget

## Demo 2 — Văn bản đến hoàn chỉnh (15')

**Bước 1 — Văn thư tiếp nhận (5')**

- Văn bản đến → Thêm mới
- Nhập thông tin văn bản mẫu (số, ngày, trích yếu, độ khẩn)
- Upload file PDF mẫu
- Lưu → Chuyển lãnh đạo

**Bước 2 — Lãnh đạo bút phê (5')**

- Chuyển sang cửa sổ tài khoản Lãnh đạo
- Mở văn bản trong inbox
- Bút phê: "Giao đ/c [tên] chủ trì, báo cáo trước [ngày]"
- Chọn người xử lý → đặt hạn → Chuyển

**Bước 3 — Chuyên viên xử lý (5')**

- Chuyển sang cửa sổ tài khoản Chuyên viên
- Mở văn bản → đọc bút phê
- Cập nhật trạng thái "Đang xử lý"
- Chuyển tiếp sang Demo 3 (tạo Văn bản đi phản hồi)

## Demo 3 — Văn bản đi + Ký số 2 kênh (25')

**Bước 1 — Soạn dự thảo (5')**

- Văn bản đi → Thêm mới
- Điền thông tin, upload file Word mẫu
- Chọn người duyệt + người ký + nơi nhận
- Gửi duyệt

**Bước 2 — Duyệt (3')**

- Chuyển sang Lãnh đạo → mở dự thảo → đọc → Duyệt
- Demo cả thao tác **Trả lại** (rồi sửa, gửi lại) cho học viên thấy

**Bước 3 — Ký số SmartCA (7')** ⭐

- Chọn "Ký số" → Chọn **SmartCA**
- Mở app SmartCA trên điện thoại (đưa điện thoại lên màn chiếu)
- Xác nhận → ký thành công
- Mở file PDF đã ký → chỉ chữ ký số trên file

**Bước 4 — Ký số Viettel CA (7')** ⭐

- Tạo văn bản 2 (đã chuẩn bị sẵn)
- Chọn "Ký số" → Chọn **Viettel CA**
- Mở app Viettel CA trên điện thoại
- Xác nhận → ký thành công
- So sánh trải nghiệm 2 kênh — kết luận: "Anh/chị quen kênh nào dùng kênh đó"

**Bước 5 — Phát hành (3')**

- Văn thư cấp số → Phát hành
- Demo trạng thái: Đã gửi → Đã nhận → Đã đọc

## Demo 4 — Hồ sơ công việc + Thông báo (5')

- Tạo 1 hồ sơ công việc → thêm văn bản vừa tạo vào hồ sơ
- Quay về Dashboard → chỉ chuông thông báo có badge → click xem
